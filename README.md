# AgriPlatform

**AgriPlatform** is an innovative and comprehensive platform designed to help farmers and agricultural professionals monitor and manage their crops and sensors efficiently. The platform integrates real-time sensor data with crop management features to provide a holistic view of agricultural operations.

## Introduction

AgriPlatform is designed to address the needs of modern agriculture by offering a digital solution for monitoring environmental conditions and managing crop data. By utilizing sensor technology, farmers can receive real-time data about soil moisture, temperature, humidity, and more, enabling them to make informed decisions to optimize crop yield and sustainability.

## Features

### Sensor Management
- **Real-time Data Monitoring**: Track environmental conditions such as temperature, humidity, soil moisture, and light levels through connected sensors.
- **Data Visualization**: View sensor data through intuitive charts and graphs that help in understanding trends and making decisions.
- **Sensor Selection**: Customize the dashboard by selecting specific sensors that are critical to your operations.

### Crop Management
- **Crop Tracking**: Manage multiple crops by storing information such as planting dates, growth stages, and expected harvest dates.
- **Notes and Observations**: Record notes and observations for each crop to track growth, issues, and other important details.
- **Growth Stage Monitoring**: Monitor the growth stages of your crops to ensure they are developing as expected.

### User Preferences
- **Personalized Dashboard**: Save your preferred sensors and crops to create a personalized dashboard that suits your specific needs.
- **Easy Customization**: Update your preferences anytime to adapt to changing needs or new sensor deployments.

### Integration and Automation
- **Automated Data Filling**: The platform automatically generates missing sensor data to ensure continuity and reliability in monitoring.
- **Secure User Authentication**: Leveraging Firebase for secure user authentication, ensuring that your data remains safe.

## Technology Stack

AgriPlatform is built using a modern technology stack to ensure reliability, scalability, and ease of use:

- **Frontend**: React.js, Tailwind CSS for responsive UI
- **Backend**: Node.js with Express.js for the API
- **Database**: MongoDB for data storage
- **Authentication**: Firebase for user authentication and secure access
- **Hosting**: Deployed on vercel ([Link](https://web-course-react-timc.vercel.app/))

## How It Works

1. **User Registration and Login**: Users sign up and log in through a secure Firebase authentication system.

2. **Dashboard Customization**: Upon logging in, users can customize their dashboard by selecting which sensors to monitor and which crops to manage.

3. **Real-time Monitoring**: The platform fetches data from connected sensors, allowing users to monitor their fields in real-time.

4. **Crop Management**: Users can add/delete their crops, update their growth stages, and log notes, ensuring that all critical crop information is stored and accessible.

5. **Data Visualization**: Sensor data is presented in a user-friendly format, making it easy to spot trends and make data-driven decisions.

6. **User Preferences**: The platform remembers your selected sensors and crops, providing a tailored experience every time you log in.


## Getting Started

AgriPlatform is designed to be user-friendly and easy to set up. Follow these steps to get started:

1. **Sign Up**: Visit the AgriPlatform website and create an account.
2. **Set Up Sensors**: Connect your environmental sensors to start collecting data.
3. **Customize Dashboard**: Select the sensors and crops you want to monitor on your dashboard.
4. **Start Monitoring**: Use the platform to monitor real-time data, track crop growth, and make informed decisions.
